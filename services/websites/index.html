Questions people ask

Do I need a booking system already?

No. If you have one, the website can link to it. If you do not, customers can contact you by email, WhatsApp or phone.

Can I use my own domain?

Yes. If you already have a domain, we can use it for your new site.

Do I have to buy an AI assistant too?

No. You can start with the website and add an assistant later if it would help.
